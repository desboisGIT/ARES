## Scoring decisions that the references do not settle

The build plan's **95% of observable space** needs an explicit versioned definition: free volume or surfaces; admissible collision-free camera poses; clearance for reachability; closed doors, occlusion, furniture, material failure and sensor range. The denominator must not depend only on the policy's actual observations, which would let hovering define an artificially small target.

A proposed initial interpretation is an evaluator-owned target set of voxels potentially visible from physically reachable camera poses under a documented idealized sensor model, with credit only for correct classifications supported by trusted observations. This is a project scoring choice, not a result established by the cited papers. Later sensor realism must version the scorer contract where it changes that target.

Also freeze floor-plan IoU class handling and bounds, evidence of room discovery, timeout and landing tolerances. Reconstruct collisions, boundary violations, elapsed time and landing from trusted episode data rather than report assertions. Keep dense training reward separate from pass/fail, and include a successful witness episode so rejecting every submission cannot satisfy the attack-policy gate.

Phase 0 needs independent contracts, validation, deterministic fixtures and scoring. It does not require integrating the research stacks or buying hardware.
