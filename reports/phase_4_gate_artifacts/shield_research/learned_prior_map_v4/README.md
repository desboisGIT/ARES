# Phase4 fixed-prior learned-command integration

This NEW positive operating protocol supplies an explicitly external,
all-direction preflight map prior from bounded first-hit ray observations. It is
not a claim that the current forward camera captured that prior, and it requires
no online exploration. Existing unknown-slab runs and failures are unchanged.

`observe_prior` performs the same public target-ray sweep as the older fixture,
with only its artificial x28 omission removed. Free cells still require the exact
robust ray witness. Occluded, occupied and unresolved cells remain unknown.
The .25m homogeneous static hard-map cells align with the actual integer-face
furniture, which also aligns with the .2m NN depth/collision grid. The world/map
lease is55s. Its complete immutable witness/lease snapshot is computed before
flight; there is NO online hard mapper, cache refresh or free-label update in the
finite control loop. Original noisy forward-depth and measured ring-map inputs
for the NN remain unchanged and separate from this prior.

Task pairs are independently generated from the declared seed before any flight
outcome. They have first leg>=.5m and second>=.9m and must fit a public witnessed
route tube padded(.3,.3,.5)m. This is input-task validity, not outcome filtering;
all attempted flights, setup failures and profile cases are retained. The exact
runtime guard still checks the actual current uncertainty family and complete
backup reserve at every command. No occupancy truth or waypoint enters the
command-to-anchor adapter.

The frozen BPTT143024-byte checkpoint retains SHA e535060b0b1f6586cb6deeaafd59b87016028c3d412257934cec2ce9ef41063f.
`--checkpoint PATH` permits portable loading but enforces that same SHA. All51
original runtime sources and the complete original randomized Gaussian NN sensor
interface remain unchanged. Controller observer/global60Hz NN clocks and queues
continue across100Hz guard renewals. Only guard epochs rebase after the unchanged
exact streaming trim/family/reserve proof admits renewal;10s cached backups,
public energy bounds and55s leases remain mandatory.

Candidate screening/scoring uses only public packets and approximate floating
arithmetic, with no authority. The exact guard and verified point kernel alone
admit/issue commands. Calibration is the original constant-thrust coast proposal;
no coverage-first exploration or alternate horizontal-hold controller is used.
Actual binary32 physical word changes are interventions.

All-in shield WALL time includes candidate generation, proof attempt, fresh token
consumption, new guard/first decision, ack/public-energy update, receipt update
and finite-worker administration. Every call>10ms fails timing. Sensor rendering,
Gaussian policy observation processing, NN inference, NN observer, plant/energy
simulation and truth oracle have separate latency fields. Preflight map/setup and
explicit static proof precomputation occur before flight. Complete receipt and
ray archival is genuinely deferred until the finite mission ends. ControlWorkerGC
has a4500-step declared limit, records RSS/counts and restores prior GC state;
it is not a worst-case timing proof or a hardware result.

One complete development mission must pass functional AND strict timing checks
before sources/settings/protocol and fresh eight-case validation are frozen.
No validation result or overall Phase4 pass is claimed by creating this protocol.
