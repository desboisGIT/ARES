# Renewable public trim and admission extensions

These NEW research modules derive another finite-horizon admission from public bounded packets and acknowledged SI command words. They do not alter the old guard, point kernel, fixed proof bundle, dynamics, Gaussian policy observations or51 frozen package sources. A renewed lease is admitted only by a new current-family inclusion and future map reservation. They do not issue a physical flight certificate or prove mission completion.

`producer.py` is the default U=.001rad/s/component, W=.01rad/s/component proof. `producerwide_v2.py` is an optional U=.02, W=.04 proof of the SAME plant/controller domain using a sharper quaternion-stage norm bound. Both expose the same API; `energy.py` and `epochs.py` work with either. All Python files are frozen and pinned in `frozen_python_sha256.json`.

## Runtime API and ownership

1. Choose a fixed binary32 target from known public issued thrust words, using `target_from_public_commands(words)`. No sampled mass, mg, motor thrust or energy enters the choice. A useful initial seed is a verified backup word at the current admitted anchor plus the two actual public queue words.
2. `recalibration_candidate(absolute_packet, old_hold, target_word)` solves a represented binary64 anchor for vertical force `Fz=target/body_z_z`. It calls the unchanged verified point kernel and requires the emitted thrust word to equal the target EXACTLY. Its existing final1e-6 error witness applies directly; no second quantization budget is added. The other commands right the current observed orientation. A candidate is window-eligible only if every issued rate meets U.
3. Send that anchor to the existing guard and issue/acknowledge its command normally. Only fresh accepted C+geometry proposals count. Fallback, rejected proposal, discontinuous clock, mismatched word or rate excess clears the window; those ticks never silently count as recalibration.
4. `PublicTrimWindow.note_issued(tick=GLOBAL_TICK, packet=ABSOLUTE_PACKET, decision=TRUSTED_GUARD_RECEIPT, acknowledged_command=ACTUAL_WORD, decision_epoch_global_tick=EPOCH)` records the completed transaction. The receipt must come from the verified guard, not an untrusted boolean supplier. Then `note_final_packet(tick=NEXT_GLOBAL_TICK,packet=NEW_ABSOLUTE_PACKET)` supplies the post-ack endpoint. At least270 consecutive issued intervals are required:70 settling intervals plus200 history intervals.
5. `window.propose(proof=...,known_map=ABSOLUTE_MAP,public_energy_upper=LEDGER.energy,service_lease_expires_tick=ABSOLUTE_EXPIRY)` derives new trim D and motor-residual y boxes, uses the actual two public NONZERO queue words in `current_terminal_membership`, and reserves the full family through another1000 steps. It requires public Eupper<=8000 and fresh hard state/map service through the whole future lease. It returns a proposal, never mutates the active guard.
6. `epochs.prepare_epoch_switch(old_guard,window,proof=...,known_map=ABSOLUTE_MAP,public_energy_upper=ledger.energy,service_lease_expires_tick=GLOBAL_EXPIRY,current_absolute_packet=packet,old_epoch_global_tick=epoch)` recomputes the admission, checks exact public queue continuity and constructs a NEW guard. It returns `new_guard`, `epoch_global_tick` and `first_decision`, already pending at localtick0. Issue that command ONCE and acknowledge it on the new guard before committing the active reference. If preparation rejects, the old guard remains untouched and retains its existing lease; this never extends an expired guarantee.

Subsequent guard packets use `rebase_packet(abs_packet,global_tick=g,epoch_global_tick=epoch)`, and `guard.decide(...tick=g-epoch)`. Policy, physical sensor and NN clocks stay global. Only monitor metadata is re-expressed. Raw p/v/q/w values, physical state, motor, actual transport queue and physical energy are never reset. `EpochMapView` queries both outward endpoints of the corresponding ABSOLUTE witness time. Packet expiry is rounded down after subtracting the epoch. No old witness's validity interval is enlarged. An acknowledgement/transport failure after issuing a new word invalidates that transaction; it must not be hidden by resuming a stale old queue.

`RenewedAdmission` subclasses the unchanged `InitialAdmission` type and is constructed only after recomputing the window and new reserve. It binds the public-history digest and fixed mathematical proof SHA. The old constructor therefore accepts the new current family without any core edit.

## Exact small-rate stage proof

The unchanged inertia-set calculation gives `wi'=-lambda_i*wi+lambda_i*ui+ci*wj*wk`, lambda in[27,34], |ci|<=1. Under |wi|<=W and |ui|<=U, the forcing bound is `r=W²+34U`. The previously established exact RK4 coefficients apply to arbitrary stage forcing values of magnitude<=r. For default U=.001/W=.01, every stage remains<=W and the five-substep macro endpoint plus1e-6 angular arithmetic is below .007941780<W. The optional U=.02/W=.04 case gives endpoint below .036672266<W. Gyro clipping stays inactive. All inequalities are exact Fractions over the full published parameter set; no measured acceleration constant is used.

The optional sharper REAL quaternion-stage bound is independently verified by exact symbolic polynomial identities. With unit q0, pure body rates w1,w2,w3 and a=h/4, reduce q0 to identity using the already proved Hamilton norm/product identities. The actual RK4 stages are q2=1+a*w1, q3=1+a*q2*w2, q4=1+2a*q3*w3. Their exact squared-norm deviations are

- q2: `a²|w1|²`;
- q3: `-2a²(w1·w2)+a²|w2|²+a⁴|w1|²|w2|²`;
- q4: `-4a²(w2·w3)-4a³((w1×w2)·w3)+4a²|q3|²|w3|²`.

For |wi|2<=Omega=3W these imply E2=a²Omega², E3=3a²Omega²+a⁴Omega⁴, E4=4a²Omega²+4a³Omega³+4a²(1+E3)Omega². Each symbolic difference is exactly zero in `compatibility.json`. Keep the old conservative q-coordinate displacement bound D=h*Omega/(2*(1-h*Omega)), normalized endpoint displacement<=2D/(1-D), and five such substeps. Then `|Rzz-1|<=max(E2,E3,E4)+2*qxmax²+2*qymax²`. At observed |qx|,|qy|≈.0014 the wide bound is below2.964e-5, still below the unchanged .0002 threshold. The loose O(h*Omega) norm defect is eliminated by an exact identity, not a safety-limit change.

Every recorded history packet must still pass the published forward-arithmetic state domain, deterministic component packet errors ep=.005m/ev=.01m/s/ew=.001rad/s, exact same-epoch raw q and8u shell. Actual queues are constant-T and bounded-rate after transport clears. A standalone original motor recurrence bound over[0,6.501] supplies2e-5N/H through settling, avoiding circular use of the narrower RPI motor domain. The post-settle absolute motor interval and current/history command bands are explicitly checked before using the full-body arithmetic budget. Failed domain checks reject renewal.

`trim_history_v2` already requires constant issued THRUST, not zero angular commands, once its q/w stage hypotheses are established. Its function is imported unchanged. The new force box is |D|<=mmax/bmin*trim_acceleration_bound; the new motor box comes from its lag/authority/settling bound. Both are rounded outward to dyadic endpoints. Current family inclusion is recomputed with current packet, anchor=current measured p, newhold=target, and the actual two small-rate queue words. No zero queue or hover-truth reset is inserted.

The existing REAL proof is invariant to the public hold parameter. In vertical error coordinates, d=Fhold-mg/b and `ez=pz-anchorz-d/(m0*kp)`, so substituting into the exact desired force gives `Fz=mg/b-m0*kp*ez-m0*kv*vz`, independent of Fhold. Motor and delayed thrust coordinates similarly reduce to actualM-mg and issuedT-mg/b. Changing the public calibration therefore changes the admitted coordinate center, not the physical equations or RPI Q/remainder/parameter proof. The new inclusion and reservation are mandatory before switching.

The producer demonstrations retain all eight public development profile cases. These runs do not close the learned cluttered mission gate. The integration agent owns long missions, new unknown-space observations, timing checks and global-clock policy execution. Hard-source availability and the enforced CPU arithmetic/backend contracts remain explicit; default Gaussian observations and physical hardware are not certified by this extension.

No deadline claim is inferred from the functional producer runs.
